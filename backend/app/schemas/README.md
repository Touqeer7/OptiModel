# Offline BPMN schemas

These files were retrieved without modification from the normative machine-readable documents linked by [OMG BPMN 2.0.2](https://www.omg.org/spec/BPMN/2.0.2/):

- https://www.omg.org/spec/BPMN/20100501/BPMN20.xsd
- https://www.omg.org/spec/BPMN/20100501/Semantic.xsd
- https://www.omg.org/spec/BPMN/20100501/BPMNDI.xsd
- https://www.omg.org/spec/BPMN/20100501/DC.xsd
- https://www.omg.org/spec/BPMN/20100501/DI.xsd

Copyright and specification terms remain with OMG and the contributors identified in the source documents. Schemas are used as an offline validation authority, not as a claim to implement every BPMN feature. Imported XML schema diagnostics are separate from the stricter executable-subset IR checks. Legacy custom unqualified timing attributes may produce XSD warnings. Generated Studio XML passes these schemas in the fixture suite.
